# Unique_Help
منوی راهنمای /help برای Unique RP (essentialmode + ESX قدیمی، بدون es_extended).

- نصب: پوشه رو بذار تو `[ARSHIA]` و تو server.cfg بنویس `ensure Unique_Help`
- کامندها: `/help` (همه) ، `/openhelp [id] [pageId]` (ادمین)
- export سرور: `exports['Unique_Help']:OpenHelpMenu(playerId, pageId)`
- event کلاینت: `unique_help:open`
- متن‌ها: `config.lua` | تنظیمات: `settings.lua`
- عکس‌ها: لیست در `ui/img/guides/IMAGES_NEEDED.txt`
