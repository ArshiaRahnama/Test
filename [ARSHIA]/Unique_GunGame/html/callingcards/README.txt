Drop your own calling-card images (.png / .gif) in this folder, then list their
filenames in Config.CallingCards in config.lua, e.g.:

    Config.CallingCards = {
        'gold.png',
        'skull.gif',
    }

A random one is shown on the MVP screen after each win. Leave Config.CallingCards
empty and the MVP screen just shows a plain star badge instead - no images required
to use the feature.
