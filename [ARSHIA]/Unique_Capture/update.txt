10- Bug Fix: The "stand in zone marker" timer could spawn multiple

    (/kos) that let anyone toggle the capture UI.

14- Bug Fix: SendKillLog didn't check if the damaged player still 
    existed (could crash if they disconnected right as they died).

51- Bug Fix: SQL errors spamming the console every 15 seconds 
    ("Duplicate column" style syntax errors on capture_gang_stats). 
    Root cause: CurrentCaptureHolders pre-fills every zone with an 
    empty placeholder table ({}) until it's actually captured — 
    CalcCaptureTimes was reading that placeholder as if it were a 
    real gang name and trying to insert an empty table into the 
    database. Fixed by only processing zones that hold an actual 
    gang-name string, with a matching defensive check added inside 
    UpsertGangStat itself too.
