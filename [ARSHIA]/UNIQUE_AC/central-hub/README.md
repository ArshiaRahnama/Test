# UNIQUE_AC — Central Hub

یه سیستم مستقل (جدا از خودِ ریسورس FiveM) که ۴ تا قابلیت رو با هم میده:

1. **داشبورد چندسروری** — یه PWA قابل نصب رو گوشی که وضعیت همه‌ی سرورهات
   رو با هم نشون میده.
2. **هشدار زنده** — وقتی یه سرور آفلاین/آنلاین میشه یا یه Quarantine مهم
   پیش میاد، تو دیسکورد خبر میده (به‌جای Web Push دست‌نویس که بدون تست
   زنده ریسک خرابی داشت — توضیحش پایین‌تره).
3. **سیستم لایسنس/اشتراک** — اگه می‌خوای UNIQUE_AC رو به بقیه هم بفروشی،
   از اینجا کلید فعال‌سازی بساز و مدیریت کن.
4. **صفحات عمومی** — یه Status Page و یه صفحه‌ی آمار ناشناس برای تبلیغ.

**این پوشه (`central-hub/`) کاملاً جدا از خودِ ریسورس FiveM هست** — باید
رو یه هاست وب PHP جدا (مثلاً `arshiahub.ir/hub`) آپلودش کنی، دقیقاً مثل
`appeal-form/`.


## چی لازم داری

- هاست وب معمولی با PHP 8+ و پشتیبانی از SQLite (تقریباً همه‌ی هاست‌های
  امروزی این رو دارن، نیازی به دیتابیس MySQL جدا نیست)
- دسترسی به Cron Job (برای تشخیص آفلاین شدن سرور — توضیح پایین)
- یه وب‌هوک دیسکورد (اختیاری ولی پیشنهاد میشه)


## نصب — قدم به قدم

### ۱. آپلود
کل پوشه‌ی `central-hub/` رو رو هاستت آپلود کن (مثلاً تو
`public_html/hub/`).

### ۲. نصاب رو باز کن
برو به `https://دامنه‌ت/hub/install.php` — یه فرم می‌بینی که ازت
می‌پرسه: پسورد داشبورد، وب‌هوک دیسکورد (اختیاری)، اسم برند. بزن
«Build the hub» و همین. نصاب خودش:

  • چک می‌کنه هاستت همه‌چیزی که لازمه رو داره (PHP، پسوند SQLite و...)
  • دیتابیس و جدول‌هاش رو می‌سازه
  • فایل `local-config.php` رو با جواب‌های تو می‌سازه (نیازی به دست‌زدن
    به کد نیست)
  • یه کلید لایسنس اول برات می‌سازه و نشونت می‌ده

⚠️ بعد از نصب موفق، یه فایل `install.lock` ساخته می‌شه و نصاب دیگه
اجازه نمی‌ده دوباره اجرا بشه (امنیتی). اگه واقعاً خواستی از اول نصب
کنی، باید خودت `install.lock` و `local-config.php` رو دستی حذف کنی.

### ۳. Cron برای تشخیص آفلاین‌شدن
یه سرور که کرش کنه یا قطع بشه، خودش نمی‌تونه به شما خبر بده که آفلاینه!
برای همین باید یه اسکریپت رو هر ۱-۲ دقیقه اجرا بشه که چک کنه. تو پنل
هاستت (cPanel یا هرچی) یه Cron Job با این خط اضافه کن:

```
*/2 * * * * php /مسیر/کامل/تا/central-hub/api/check-offline.php >/dev/null 2>&1
```

### ۴. کلیدهای لایسنس بیشتر (اختیاری)
اگه بیشتر از یه کلید لازم داری (مثلاً برای فروش به چندتا مشتری)، از
`dashboard/login.php` وارد شو و بعد به `../admin/keys.php` برو.

### ۵. وصل کردن سرور FiveM
تو `configs/fire-config.lua` خودِ ریسورس UNIQUE_AC:

```lua
UNIQUE_AC.CentralHub = {
    Enable              = true,
    URL                 = "https://دامنه‌ت/hub",
    LicenseKey          = "UAC-XXXXXXXXXXXXXXXXXXXX",  -- از قدم ۵
    ServerName          = "نام سرورت",
    HeartbeatIntervalMs = 60000,
    NotifyOnQuarantine  = true
}
```

سرور رو ری‌استارت کن — تا ۶۰ ثانیه بعد باید تو داشبورد ظاهر بشه.


## چطور "نصب رو گوشی" کار می‌کنه (PWA)

با گوشی برو به `https://دامنه‌ت/hub/dashboard/` (بعد از لاگین). تو
کروم/سافاری گزینه‌ی «Add to Home Screen» رو بزن — یه آیکون رو صفحه‌ی
اصلی گوشیت میاد که مثل یه اپ واقعی باز میشه، بدون نوار آدرس مرورگر.


## چرا Web Push واقعی نه، دیسکورد؟

پوش نوتیفیکیشن مرورگر (Web Push) نیاز به رمزنگاری VAPID داره (ECDH +
HKDF + AES-GCM) که دست‌نویسی‌ش بدون تست زنده رو یه سرور واقعی، ریسک
بالایی داره که یه‌جا بشکنه و اصلاً معلوم نشه. دیسکورد یه کانال
اثبات‌شده‌ست (همینی که خودِ UNIQUE_AC از اول برای لاگ استفاده می‌کنه) و
اپ موبایل دیسکورد خودش پوش نوتیفیکیشن واقعی می‌فرسته — پس به‌جای
دوباره‌سازی یه چیز پیچیده و پرریسک، از یه چیز ثابت‌شده استفاده کردم.
اگه بعداً خواستی، یه کتابخونه‌ی Web Push مثل `web-push-php` (از طریق
Composer) می‌تونه بعداً اضافه بشه.


## صفحات عمومی

- `https://دامنه‌ت/hub/status.php` — وضعیت کلی (چندتا سرور آنلاینن)
- `https://دامنه‌ت/hub/showcase.php` — آمار ناشناس برای تبلیغ (فقط
  عدد کل، هیچ اسم پلیر یا سروری نشون داده نمی‌شه)


## امنیت

- فایل `hub.db` با `.htaccess` از دانلود مستقیم محافظت شده (فقط رو
  Apache — اگه هاستت Nginx هست، باید دستی این خط رو به کانفیگ سایتت
  اضافه کنی: `location ~ \.db$ { deny all; }`)
- پسورد داشبورد رو قوی بذار و عوضش کن از مقدار پیش‌فرض `config.php`
- کلیدهای لایسنس تصادفی و طولانی‌ان (۲۰ کاراکتر هگز) — عملاً غیرقابل حدس
