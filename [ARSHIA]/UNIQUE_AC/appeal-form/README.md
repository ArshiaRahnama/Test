# UNIQUE_AC — Ban Appeal Form

این یه فایل PHP مستقله — **بخشی از ریسورس FiveM نیست**. جدا آپلودش کن رو
هاست وب خودت (مثلاً `arshiahub.ir/appeal`).

## نصب

1. فایل `index.php` رو رو هاستت آپلود کن (هر هاست معمولی PHP + دسترسی به
   همون دیتابیس MySQL که سرور FiveM ازش استفاده می‌کنه کافیه).
2. بازش کن و این ۴ خط بالای فایل رو با اطلاعات دیتابیس واقعی‌ت پر کن:
   ```php
   $DB_HOST = "127.0.0.1";
   $DB_NAME = "your_database_name";
   $DB_USER = "your_database_user";
   $DB_PASS = "your_database_password";
   ```
3. همین. جدول‌های `uniqueac_banlist` و `uniqueac_appeals` از قبل با خود
   ریسورس ساخته می‌شن، نیازی به کار اضافه نیست.

## چطور کار می‌کنه

1. پلیر بن‌شده license identifier خودش رو وارد می‌کنه.
2. فرم چک می‌کنه که واقعاً بن‌شده و اعتراض pending دیگه‌ای نداره.
3. یه متن اعتراض می‌نویسه و می‌فرسته.
4. تو خودِ پنل UNIQUE_AC (تب Appeals) ادمین‌ها می‌تونن Approve (آنبن خودکار)
   یا Reject کنن.

## چرا این‌طوری، نه مستقیم از خودِ سرور FiveM؟

FXServer فقط یه `SetHttpHandler` فعال در کل می‌تونه داشته باشه — اگه
ریسورس خودمون بخواد این کارو انجام بده، ریسک داره که txAdmin یا یه
ریسورس دیگه که به همون سیستم وابسته‌ست رو بی‌سروصدا خراب کنه. یه فایل PHP
ساده رو هاست خودت که از قبل داری، این ریسک رو کاملاً حذف می‌کنه.
