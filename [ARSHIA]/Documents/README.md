# Unique RP — Official Documents

توسعه: **Arshia** — [arshiahub.ir](https://arshiahub.ir)

## خلاصه‌ی وضعیت فعلی (نسخه‌ی نهایی)

- **باز کردن منو:** کلید **F9** (بدون کامند) — همه می‌تونن باز کنن و مرور کنن.
  گزینه‌های ساخت/ویرایش/بستن/کپی/اشتراک/حذف فقط برای شغل `police` نشون داده می‌شن،
  و سمت سرور هم مستقل دوباره چک می‌شن (حتی اگه کلاینت دستکاری بشه).
- **ناوبری تو منو (icon_menu):**
  - کلیک چپ = انتخاب
  - بالا/پایین = جابه‌جایی
  - Backspace = یه پله برگرد؛ اگه تو منوی اصلی باشی، کل منو رو می‌بنده
  - Esc = بستن کامل منو
  - بدون کرسر موس روی صفحه، بدون گرفتن کنترل بازی
- **سندهای «کپی برابر اصل»:** یه ستون مجزا (`is_copy`) دارن؛ فقط نمایش/حذف/بازگشت
  دارن — نه ویرایش، نه بستن، نه کپیِ کپی، نه اشتراکِ مستقیم از این مسیر.
- **سند بسته‌شده:** دیگه قابل ویرایش یا بستنِ دوباره نیست.
- **اسم سند رو تو خود سند:** «اسناد رسمی Unique RP»

## نصب
1. `es_extended`، `mysql-async`، و `icon_menu` (نسخه‌ی فیکس‌شده‌ای که جدا فرستادم) باید
   قبل از این ریسورس `ensure` شده باشن.
2. `install.sql` رو دستی اجرا کن، یا بذار `Server.lua` خودش موقع اولین استارت
   جدول‌ها و ستون `is_copy` رو بسازه (این کار خودکار و امن هر بار استارت انجام می‌شه).
3. این پوشه رو جایگزین نسخه‌ی قبلی کن، `restart Documents` بزن.
4. کلید **F9** برای منو، دستور `/mydocuments` برای شهروندانی که سندی دریافت کردن.

## دیباگ
یه خط لاگ عمداً نگه داشته شده تو کنسول سرور برای عیب‌یابی سریع دسترسی‌ها:
```
[Documents] OpenListMenu(<model|document>): job=<jobname> canCreate=<true|false>
```
اگه یه روز دوباره چیزی عجیب دیدی (مثلاً دکمه‌ی ساختن نیست)، همین خط رو نگاه کن —
`job` باید دقیق شغل بازیکن باشه و `canCreate` باید بر اساس `Config.lua` درست باشه.

## icon_menu — باگ اصلیش
تو `icon_menu/Client/Main.lua`، حلقه‌ای که کلیدها رو می‌خونه و به NUI می‌فرسته
کامنت شده بود (کد مرده) — منو باز می‌شد ولی هیچ راهی برای پیمایش/بستن نبود.
الان با موس + کیبورد (بدون کرسر) از نو نوشته شده. فایل `icon_menu_fixed.zip`
جداست — محتوای پوشه‌ش رو جایگزین `icon_menu` فعلیت کن.
