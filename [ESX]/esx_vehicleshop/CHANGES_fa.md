# آپدیت نمایشگاه ماشین (esx_vehicleshop)

## چی اضافه شد
- **منوی گرافیکی جدید (NUI)** به‌جای منوی متنی قدیمی - وقتی کنار خودرو می‌ایستید و E رو می‌زنید.
- **دوربین چرخشی** دور خودروی انتخاب‌شده - با کشیدن ماوس یا دکمه‌ی «چرخش خودکار».
- **کارت مشخصات فنی** هر خودرو - سرعت، شتاب، ترمز، تعداد سرنشین (از خود بازی خونده می‌شه).
- **تست‌درایو** - با زمان محدود (پیش‌فرض ۱۲۰ ثانیه)، اگه از نمایشگاه خیلی دور بشید یا زمان تموم بشه یا Backspace بزنید، ماشین برگردونده می‌شه.
- **خرید اقساطی** - پیش‌پرداخت + چند قسط با سود، به‌صورت خودکار هر ۲۴ ساعت از حساب بانکی کسر می‌شه. اگه ۳ قسط پشت‌سرهم پرداخت نشه، ماشین توسط نمایندگی ضبط می‌شه.
- **معاوضه با ماشین قدیمی** - هر خودروی پارک‌شده‌ی (stored) خودتون رو می‌تونید موقع خرید به‌عنوان بخشی از قیمت رد کنید.

بخش کارمندی/نمایندگی (Reseller, Boss Actions, Stock, Rent) دست نخورده باقی مونده - این آپدیت فقط روی تجربه‌ی مشتری (خرید شخصی) بوده.

## قبل از نصب
۱. فایل `esx_vehicleshop.sql` رو دوباره روی دیتابیس اجرا کنید (فقط یک جدول جدید `vehicleshop_financing` اضافه می‌کنه، به هیچ‌کدوم از جدول‌های قبلی دست نمی‌زنه).
۲. کل پوشه‌ی `esx_vehicleshop` رو جایگزین نسخه‌ی قبلی کنید.
۳. سرور/ریسورس رو ری‌استارت کنید (`ensure esx_vehicleshop` یا `restart esx_vehicleshop`).

## تنظیمات (`config.lua`)
همه‌چیز از این بخش قابل تغییره:

```lua
Config.UseModernShopUI = true   -- false = برگشت به منوی متنی قدیمی
Config.TestDrive  = { Enable, Duration, MaxDistance, EndKey }
Config.Financing  = { Enable, MinDownPaymentPercent, InterestPercent, Installments, PaymentIntervalHours, MaxMissedPayments }
Config.TradeIn    = { Enable, PayoutPercent }
```

اگه هرکدوم از بخش‌های اقساط/معاوضه/تست‌درایو رو نمی‌خواید، کافیه `Enable = false` کنید، دکمه‌ی مربوطه توی منو خودش مخفی می‌شه.

## نکته‌ی امنیتی
قیمت‌ها همیشه سمت سرور و از جدول `vehicles` خونده می‌شن - کلاینت فقط اسم مدل و پلاک رو می‌فرسته، نه هیچ عدد قیمتی. یعنی مثل قبل، دستکاری کلاینت نمی‌تونه قیمت خرید رو تغییر بده.
