# esx_property PLUS — راهنمای نصب

این نسخه از `esx_property` خودت با این فیچرهای جدید (نوشته‌شده از صفر، نه کپی از منابع دیگه) گسترش پیدا کرده:

## فیچرهای اضافه‌شده
1. **ارتقای انبار / گاوصندوق** — چند سطح، قیمت پلکانی (`config_plus.lua` → `ConfigPlus.StorageTiers` / `SafeTiers`)
2. **فرنیچر پلیسمنت** — کاتالوگ خرید (`ConfigPlus.FurnitureCatalog`) + جانمایی با کیبورد و NUI (`nui/furniture.html`)
3. **بازار بین بازیکن‌ها** — گذاشتن خونه برای فروش، خرید از بازیکن دیگه، کارمزد قابل تنظیم
4. **رهن/اقساط** — پیش‌پرداخت + قسط روزانه‌ی خودکار (کران روزانه ساعت ۲۱:۰۰)
5. **رنگ‌بندی وضعیت روی نقشه** — بلیپ و تکست سه‌بعدی بالای مارکر بسته به وضعیت (قابل خرید/مال خودت/برای فروش/مال یکی دیگه)

## نصب
1. فایل‌های زیر رو داخل پوشه‌ی `esx_property` بریز (کنار فایل‌های قبلی):
   - `config_plus.lua`
   - `server/plus.lua`
   - `client/plus.lua`
   - `client/furniture.lua`
   - `nui/furniture.html`
2. `fxmanifest.lua` همین پکیج، آپدیت‌شده و شامل رفرنس همه‌ی فایل‌های بالاست — جایگزین قبلیت کن (یا خودت دستی entry هارو اضافه کن).
3. `esx_property_plus.sql` رو روی دیتابیست اجرا کن (بعد از جدول‌های اصلی `esx_property`).
4. سرور رو ری‌استارت کن.

## نکاتی که باید خودت تنظیم کنی
- **کلید فعال‌سازی ماوس در حالت جانمایی**: `Left Alt` رو نگه‌دار تا دکمه‌های پنل NUI کلیک‌پذیر بشن (کنترل بازی موقتاً غیرفعال میشه)؛ دوباره بزن تا برگردی به کنترل کیبوردی (WASD/PageUp-PageDown/اسکرول). اگه با کلید دیگه‌ای تو سرورت تداخل داشت، `control 19` رو تو `client/furniture.lua` عوض کن.
- **مدل‌های فرنیچر** (`ConfigPlus.FurnitureCatalog`): چندتا مدل نمونه‌ی وانیلای GTA گذاشتم؛ اگه پک فرنیچر اختصاصی (stream شده) داری، اسم مدل‌هاشو همینجا جایگزین کن.
- **یکپارچه‌سازی با اینونتوری** (`client/plus.lua` → `syncLevels`): جایی که کامنت گذاشتم رو باید بر اساس اینونتوری خودت (`esx_inventory` یا هرچی) کامل کنی تا سطح انبار واقعاً روی maxWeight صندوق property اثر بذاره.
- **ضبط خونه در صورت نپرداختن قسط**: فعلاً پیاده نشده (فقط اعلان میده که پول کافی نبوده). اگه خواستی می‌تونیم شمارنده‌ی «قسط عقب‌افتاده» و مکانیزم ضبط/فروش اجباری خونه رو هم اضافه کنیم.
- **پرداخت به فروشنده‌ی آفلاین**: مستقیم به `bank_accounts` دیتابیس اضافه میشه؛ اگه ساختار جدول بانکت فرق داره (مثلاً چندحسابی/JSON)، اون بخش رو در `server/plus.lua` → `buyFromPlayer` تطبیق بده.
