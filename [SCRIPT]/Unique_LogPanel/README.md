# 🗂️ Unique_LogPanel

پنل لاگ زیبا و تب‌بندی‌شده برای ادمین‌ها و باس‌های شغل — یه رابط NUI که مستقیم از دیتابیس همون
سیستم لاگ (`[SCRIPT]/logs`) که قبلاً ساخته شده می‌خونه، پس نیازی به تنظیم اضافه نداره.

## ✅ نصب (فقط ۲ قدم)

1. فایل `install.sql` رو یه‌بار روی دیتابیس سرورت اجرا کن (phpMyAdmin / HeidiSQL / adminer).
2. تو `server.cfg`:
   ```
   ensure logs
   ensure Unique_LogPanel
   ```
   (باید بعد از `logs` استارت بشه، چون از خروجی `SendToSite` همون ریسورس استفاده می‌کنه.)

همین. از این لحظه به بعد، **هر لاگی که قبلاً به دیسکورد/سایت می‌رفت، خودکار تو این پنل هم هست** —
چون منبعش همون تابع `SendToSite` مشترکه که الان هم‌زمان تو دیتابیس هم می‌نویسه.

## 🎮 استفاده

| کی | چطور | چی می‌بینه |
|---|---|---|
| **ادمین** (permission_level بالای `Config.AdminPermissionLevel` تو `server/main.lua`) | کامند `/adminlogs` | **همه‌ی** دسته‌ها و **همه‌ی** شغل‌ها |
| **باس هر شغل** | کامند `/myjoblogs`، یا از داخل بازی: منوی باس (F6 یا هرچی باینده) → گزینه‌ی «🗂️ Mosahede Logha (LogPanel)» | **فقط** لاگ‌های شغل خودشون |

باس هیچ‌وقت لاگ شغل دیگه‌ای رو نمی‌بینه — این چک سمت **سرور** انجام می‌شه (نه کلاینت)، پس
غیرقابل دور زدنه.

## 🔌 وصل‌کردن به هر منوی دیگه (باس‌منوی سفارشی خودت)

اگه شغلی منوی باس جدا و اختصاصی خودشو داره (نه از طریق `esx_society`)، کافیه از هر جای کلاینتی
این خط رو صدا بزنی:
```lua
TriggerServerEvent('LogPanel:OpenForJob')
```
یا اگه می‌خوای از سمت سرور یه ریسورس دیگه صداش بزنی:
```lua
exports['Unique_LogPanel']:OpenLogPanel(source)
```

برای باز‌کردن نسخه‌ی کامل ادمین از سمت سرور یه ریسورس دیگه:
```lua
exports['Unique_LogPanel']:OpenAdminLogPanel(source)
```

یه نمونه‌ی واقعی و کارکردی از همین الان تو `esx_society/client/main.lua` وصل شده — چون
`OpenBossMenu` تو اون فایل مشترک بین **همه‌ی شغل‌ها**ست، دکمه‌ی لاگ خودکار تو منوی باس همه‌شون
(پلیس، مکانیک، آمبولانس، کافه، ...) ظاهر می‌شه.

## ⚙️ تنظیمات

تو `server/main.lua`:
```lua
Config.AdminPermissionLevel = 5  -- حداقل سطح دسترسی برای پنل کامل ادمین
Config.LogsPerPage = 50          -- تعداد لاگ در هر صفحه
```

## 🎨 ظاهر

تیره، شیشه‌ای (glassmorphism)، تب‌بندی‌شده بر اساس دسته (رنگ/آیکون جدا برای هرکدوم)، سرچ زنده،
صفحه‌بندی، و مودال جزئیات کامل هر لاگ. دسته‌های ناشناخته هم خودکار یه ظاهر خنثی می‌گیرن، پس
اضافه‌کردن دسته‌ی لاگ جدید تو آینده هیچ‌وقت باعث خرابی UI نمی‌شه.
