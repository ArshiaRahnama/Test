# 🗂️ Unique_LogPanel (v2)

پنل لاگ زیبا، تب‌بندی‌شده و حالا با **آمار زنده، خروجی CSV، حذف کنترل‌شده و اعلان لحظه‌ای لاگ جدید**
برای ادمین‌ها و باس‌های شغل — یه رابط NUI که مستقیم از دیتابیس همون سیستم لاگ (`[SCRIPT]/logs`) که
قبلاً ساخته شده می‌خونه، پس نیازی به تنظیم اضافه نداره.

## ✅ نصب (۳ قدم)

1. فایل `install.sql` رو یه‌بار روی دیتابیس سرورت اجرا کن (phpMyAdmin / HeidiSQL / adminer).
   اگه از v1 آپدیت می‌کنی، دوباره اجرا کردنش مشکلی نداره (ایندکس‌های جدید با `IF NOT EXISTS` نیستن؛
   اگه ایندکس تکراری خطا داد، فقط همون خط `KEY` رو حذف کن، جدول اصلی دست‌نخورده می‌مونه).
2. تو `server.cfg`:
   ```
   ensure logs
   ensure Unique_LogPanel
   ```
   (باید بعد از `logs` استارت بشه، چون از خروجی `SendToSite` همون ریسورس استفاده می‌کنه.)
3. فایل `esx_society/client/main.lua` رو با نسخه‌ی داخل پکیج جایگزین کن (یا فقط دوتکه‌کد مشخص‌شده
   با کامنت `Unique_LogPanel` رو داخل تابع `OpenBossMenu` خودت کپی کن) — این همون قسمتیه که دکمه‌ی
   «🗂️ Mosahede Logha (LogPanel)» رو به باس‌منوی **همه‌ی شغل‌ها** اضافه می‌کنه.

همین. از این لحظه به بعد، **هر لاگی که قبلاً به دیسکورد/سایت می‌رفت، خودکار تو این پنل هم هست**.

## 🐛 فیکس‌های این آپدیت

- **اتصال واقعی به باس‌منو**: نسخه‌ی قبلی توی README ادعا می‌کرد به `esx_society` وصله، ولی عملاً
  وصل نبود (دکمه‌ای تو منوی باس وجود نداشت). الان واقعاً وصل شده — تابع `OpenBossMenu` یه آیتم
  «🗂️ Mosahede Logha (LogPanel)» داره که فقط برای گرید `boss` نشون داده می‌شه.
- **باز شدن فقط از باس‌منو + `/myjoblogs`**: کلید میان‌بر F9 که تو نسخه‌ی قبل اضافه شده بود حذف
  شد، چون قرار بود پنل فقط از این دو مسیر باز بشه، نه با کلید مستقل.
  با `Config.AdminPermissionLevel` بالا، `/adminlogs` هم فقط برای ادمین‌ها باز می‌مونه.
- **باگ ستون «زمان»**: بسته به تنظیمات `oxmysql`، مقدار `created_at` گاهی به‌جای رشته‌ی تاریخ،
  به‌صورت عدد epoch (میلی‌ثانیه) برمی‌گرده و به‌شکل خام (مثلاً `1789023869000`) تو جدول نمایش داده
  می‌شد. الان هم تو NUI (نمایش جدول/جزئیات) و هم تو خروجی CSV، این حالت تشخیص داده می‌شه و درست
  فرمت می‌شه.

## 🎮 استفاده

| کی | چطور | چی می‌بینه |
|---|---|---|
| **ادمین** (`permission_level` بالای `Config.AdminPermissionLevel`، یا عضو `Config.AceAdminGroup` اگه `Config.UseAceAdmin = true`) | کامند `/adminlogs` | **همه‌ی** دسته‌ها، **همه‌ی** شغل‌ها، داشبورد آمار کامل، خروجی CSV، حذف لاگ |
| **باس هر شغل** (هر گریدی که تو `Config.BossGradeNames` باشه) | کامند `/myjoblogs`، یا از باس‌منو (`esx_society`) → «🗂️ Mosahede Logha (LogPanel)» | **فقط** لاگ‌های شغل خودشون + داشبورد آمار همون شغل + خروجی CSV شغل خودشون |

باس هیچ‌وقت لاگ شغل دیگه‌ای رو نمی‌بینه — این چک سمت **سرور** انجام می‌شه، پس غیرقابل دور زدنه.

## 🆕 امکانات جدید نسبت به نسخه‌ی قبل

- **📊 داشبورد آمار**: تب جدا تو سایدبار — کل لاگ‌ها، لاگ‌های امروز، پرتکرارترین دسته‌ها و
  (برای ادمین) پرتکرارترین شغل‌ها، به‌صورت نمودار میله‌ای، هماهنگ با فیلترهای فعال.
- **⬇️ خروجی CSV**: با همون فیلترهای فعلی (دسته/شغل/سرچ/بازه‌ی تاریخ)، تا سقف
  `Config.MaxExportRows` ردیف، مستقیم دانلود می‌شه — قابل غیرفعال‌کردن با `Config.EnableExport`.
- **🗑️ حذف لاگ (فقط ادمین)**: از داخل ردیف جدول یا مودال جزئیات، با تاییدیه؛ خودِ حذف هم
  به‌عنوان یه لاگ جدید (`logpanel_delete`) ثبت می‌شه که کی، کِی، چه لاگی رو حذف کرده —
  قابل غیرفعال‌کردن با `Config.EnableDelete`.
- **🔔 اعلان لحظه‌ای لاگ جدید**: وقتی پنل بازه، بدون رفرش دستی یه بنر بالای جدول و یه صدای کوتاه
  خبر می‌ده که لاگ جدید اومده — کلیک روی بنر همون لحظه بارگذاری می‌کنه.
  قابل غیرفعال‌کردن با `Config.EnableLiveUpdates`.
- **📅 فیلتر بازه‌ی تاریخ** + چیپ‌های سریع «امروز / ۷ روز اخیر / ۳۰ روز اخیر / همه».
- **↕️ مرتب‌سازی**: کلیک روی هدر ستون یا سلکت‌باکس، بر اساس زمان/دسته/شغل/پلیر، صعودی یا نزولی.
- **📄 تعداد ردیف در هر صفحه** قابل انتخاب (`Config.PerPageOptions`).
- **🔍 هایلایت نتیجه‌ی سرچ** داخل جدول.
- **📋 کپی سریع پیام** از داخل مودال جزئیات.
- **🔐 دسترسی ادمین از دو مسیر**: `permission_level` ESX یا (اختیاری) گروه ACE، برای
  سرورهایی که می‌خوان دسترسی پنل رو جدا از سیستم پرمیشن اصلی مدیریت کنن.
- **🧑‍✈️ چند گرید باس هم‌زمان**: `Config.BossGradeNames` می‌تونه چند اسم گرید داشته باشه
  (مثلاً `{'boss','owner'}`)، نه فقط `boss`.
- **🧹 پاک‌سازی خودکار لاگ‌های قدیمی**: با `Config.RetentionDays` (پیش‌فرض ۳۰ روز)، هر ۶ ساعت
  یه‌بار خودکار چک می‌شه؛ با صفرکردنش غیرفعال می‌شه.
- **🛡️ سخت‌تر شدن امنیت سرچ**: کاراکترهای خاص `%` و `_` تو عبارت جست‌وجو escape می‌شن تا
  نتیجه‌ی غیرمنتظره یا استفاده‌ی سوءاستفاده‌گرانه از الگوی LIKE ممکن نباشه.

## 🔌 وصل‌کردن به هر منوی دیگه (باس‌منوی سفارشی خودت)

اگه شغلی منوی باس جدا و اختصاصی خودشو داره (نه از طریق `esx_society`)، کافیه از هر جای کلاینتی
این خط رو صدا بزنی:
```lua
TriggerServerEvent('LogPanel:OpenForJob')
```
یا اگه می‌خوای از سمت سرور یه ریسورس دیگه صداش بزنی:
```lua
exports['Unique_LogPanel']:OpenLogPanel(source)
```

برای باز‌کردن نسخه‌ی کامل ادمین از سمت سرور یه ریسورس دیگه:
```lua
exports['Unique_LogPanel']:OpenAdminLogPanel(source)
```

یه نمونه‌ی واقعی و کارکردی از همین الان تو `esx_society/client/main.lua` وصل شده — چون
`OpenBossMenu` تو اون فایل مشترک بین **همه‌ی شغل‌ها**ست، دکمه‌ی لاگ خودکار تو منوی باس همه‌شون
(پلیس، مکانیک، آمبولانس، کافه، ...) ظاهر می‌شه.

## ⚙️ تنظیمات (`server/main.lua`)

```lua
Config.AdminPermissionLevel = 5          -- حداقل permission_level ESX برای دسترسی کامل ادمین
Config.UseAceAdmin   = false             -- true کن اگه می‌خوای دسترسی رو با ACE گروه مدیریت کنی
Config.AceAdminGroup = 'logpanel.admin'  -- add_ace group.logpanel.admin logpanel.access allow

Config.BossGradeNames = { 'boss' }       -- می‌تونی چند اسم گرید اضافه کنی: {'boss','owner'}

Config.LogsPerPage    = 50               -- مقدار پیش‌فرض تعداد لاگ در هر صفحه
Config.PerPageOptions = { 25, 50, 100, 200 }

Config.RetentionDays  = 30               -- پاک‌سازی خودکار لاگ‌های قدیمی‌تر از این تعداد روز (۰ = غیرفعال)

Config.EnableExport      = true          -- اجازه‌ی خروجی CSV
Config.EnableDelete      = true          -- اجازه‌ی حذف لاگ توسط ادمین
Config.EnableLiveUpdates = true          -- اعلان لحظه‌ای لاگ جدید وقتی پنل بازه
Config.LiveUpdateIntervalMs = 4000       -- فاصله‌ی چک لاگ جدید (میلی‌ثانیه)
Config.MaxExportRows     = 5000          -- سقف تعداد ردیف قابل‌خروجی در هر درخواست
Config.MaxSearchLength   = 100           -- سقف طول عبارت جست‌وجو
```

## 🎨 ظاهر

تیره، شیشه‌ای (glassmorphism)، تب‌بندی‌شده بر اساس دسته (رنگ/آیکون جدا برای هرکدوم)، سرچ زنده با
هایلایت نتیجه، فیلتر بازه‌ی تاریخ، مرتب‌سازی، صفحه‌بندی، داشبورد آماری، خروجی CSV، حذف کنترل‌شده،
اعلان لحظه‌ای لاگ جدید، و مودال جزئیات کامل هر لاگ. دسته‌های ناشناخته هم خودکار یه ظاهر خنثی
می‌گیرن، پس اضافه‌کردن دسته‌ی لاگ جدید تو آینده هیچ‌وقت باعث خرابی UI نمی‌شه.
